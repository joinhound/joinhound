# joinhound

> **Status: pre-alpha.** The first usable release is under development.

Joinhound is an open-source context layer for agents. It discovers relationships
across PostgreSQL data and S3 documents, then exposes related records and
passages—with provenance—through MCP.

The project is licensed under the Apache License 2.0.

## Installation

The package published by the initial `v0.0.1` release only reserves the project
name and exposes the future command-line entry points:

```console
uvx joinhound --version
```

Development documentation will be added as the MVP is implemented.
